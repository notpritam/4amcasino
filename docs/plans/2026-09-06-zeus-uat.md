# Zeus interface and end-to-end UAT

Use the official Zeus UI 0.2.3 SDK and tokens from myzeusui.com. The app has one
appearance: white canvas, quiet neutral surfaces, Inter typography, blue actions,
and the Zeus floating icon sidebar. The 3D lounge keeps its immersive night scene
and transparent controls, with the same action language and blue accent.

Implementation:

- Replace theme selectors with useful settings access; ignore legacy stored themes.
- Adapt shared buttons and fields to Zeus while retaining native form contracts.
- Replace navigation with an accessible, collapsible icon rail and mobile drawer.
- Use Zeus chart frames for real poker history, including losses and empty states.
- Align marketing, account, lobby, and table controls to the single visual system.

Acceptance:

- Register/login, create/join a room, obtain chips, ready/deal/play a full hand.
- Verify history/replay, ledger/settlement, profile/preferences, navigation, logout.
- Check 2D/3D parity, stable canvas size, lounge movement and quick actions.
- Check keyboard navigation, form errors, mobile layouts, empty and populated charts.
- Run typecheck, production build, the regression suite, and browser UAT against an
  isolated local database. Record outcomes and any limits in the QA report.

Keep changes local for review; publishing is a separate user action.
