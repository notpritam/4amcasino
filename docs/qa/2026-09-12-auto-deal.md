# Auto-deal control and fallback — local QA

Branch: `feat/auto-deal-fallback`. This follow-up is local, with no push or deployment.

## Behavior

- Table menu → Auto-deal is available to members in desktop 2D, phone 2D and the 3D Table menu. The host can toggle it; other members can see the saved setting, selected automatic dealer and countdown/readiness status.
- `rooms.auto_deal` persists the switch. Existing automatic behavior remains enabled by default. Enabled rooms begin a 15-second countdown once at least two seated, funded, connected players are available, including when they reconnect.
- The host is preferred only while eligible. Otherwise the first eligible player by seat is the automatic dealer. Spectators, sitting-out players, unfunded seats and the platform account are excluded. Automatic dealer selection does not change the poker button or grant host/banking permissions; the existing offline-host handover remains separate.
- The server still runs its 20-second ready check and respects each account's Auto ready preference. Only ready players still eligible at resolution are dealt in. At least two are required.
- Disabling cancels pending countdowns and ready checks immediately; a running hand finishes normally. Archived rooms cannot auto-deal. Too few ready players pause the process instead of looping prompts; the host can retry, and changes to eligible players resume it.
- Reconnecting clients receive the authoritative countdown and ready check. Ordinary state broadcasts never restart the countdown. Save failures remain visible and preserve the saved switch state.

## Manual regression

1. Join one room with three funded seated accounts. Open Table → Auto-deal in 2D and 3D; verify only the host can change the switch.
2. Turn it off and refresh. It remains off; no ready check starts. Turn it on and verify the countdown and host name appear on all clients.
3. Have the host leave the room before the countdown finishes. The next online seat becomes the fallback, while the two remaining players receive the ready check and can complete a hand.
4. Repeat with the host sitting out or standing up, then with only one eligible player remaining. Auto-deal pauses until a second eligible player returns.
5. Disable during a ready check: it closes and no hand starts. Disable during a running hand: that hand settles normally and no next countdown is scheduled.
6. Ignore a ready check: the room pauses rather than repeatedly prompting. As host, choose Try ready check again. Check reconnection during both the countdown and ready check.
