# 4AM Casino

An open-source, self-hostable web app for playing no-limit Texas Hold'em with friends, where
**no one — not even the server operator — can see a card they shouldn't**. Card secrecy comes
from a mental-poker protocol run in the players' browsers; the server only coordinates and
relays. Chips are play money tracked in a banker-approved, hash-chained IOU ledger so the group
can settle up outside the app. No real payments, ever.

**Status: work in progress.** See `docs/superpowers/specs/` for the design.
